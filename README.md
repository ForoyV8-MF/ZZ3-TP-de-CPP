# ZZ3 - TP de C++

# Décommenter le fichier CMakeLists.txt

Dans les fonctions set(), décommenter les lignes que vous souhaitez considérer.

## Faire fonctionner CMake

Construire un répertoire build --> mkdir build dans tp_1
En faire le dossier courant --> cd build
Taper cmake .. (Le .., répertoire parent est important)

## Lancer le MakeFile

Dans le répertoire build, un Makefile doit être apparu
L'éxécuter via la commande make
